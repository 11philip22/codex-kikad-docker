# LCSC Parts

To find components on LCSC, use the configured `pcbparts` MCP and its live tool descriptions.

- Report the exact manufacturer part number and LCSC code for selected parts.
- Verify the exact package, pinout, and electrical limits against the manufacturer's datasheet.
- When a selected part has EasyEDA assets, use the `easyeda2kicad` skill to import it into KiCad.
